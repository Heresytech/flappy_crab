# flappy_crab
Цель проекта - научиться создавать  приложения с помощью кроссплатформенного программного интерфейса  OpenGL на высокоуровневом языке программирования c++.
В папке .vscode находятся файлы для сборки проекта с помощью приложения Visual Studio code. Для сборки проекта нужно использовать систему CMake.
