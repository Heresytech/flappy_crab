# flappy_crab
Цель проекта - научиться создавать  приложения с помощью кроссплатформенного программного интерфейса  OpenGL на высокоуровневом языке программирования c++.
В папке .vscode находятся файлы для сборки проекта с помощью приложения Visual Studio code. В скором времени проект обретёт cmake или makefile. После сборки приложения в папку с .exe файлом 
необходимо переместить файл динамической библиотеки glfw3.dll, без которой функционирование игры(будущей) будет невозможно. P.S необходимо проверить путь до своего компилятора си++, т.к 
ваш путь и путь на моём компьюетере могут различаться.
